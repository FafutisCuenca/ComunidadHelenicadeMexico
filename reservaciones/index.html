Flujo de trabajo recomendado

1. Carga la versión vigenteSi el módulo solicita un archivo JSON, selecciona la copia más reciente de las reservaciones.
2. Registra o editaRealiza los cambios en uno de los módulos. Evita trabajar al mismo tiempo con copias distintas.
3. Exporta el JSONDescarga el archivo actualizado y consérvalo como la versión vigente.
4. Usa esa misma versiónCuando abras el otro módulo, carga el JSON actualizado para trabajar con los cambios más recientes.
Importante: GitHub Pages publica los archivos, pero no guarda automáticamente dentro del repositorio los cambios realizados desde el navegador. Para conservar las altas y modificaciones, exporta el JSON actualizado. Si deseas que la versión publicada del archivo cambie, tendrás que actualizarla manualmente en GitHub. Los cambios que no se exporten pueden perderse al cerrar o recargar la página.
