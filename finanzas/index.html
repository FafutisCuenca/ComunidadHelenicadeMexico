7. Integración de reservaciones

Importa el JSON v2 generado por el módulo de reservaciones. La importación es de solo lectura respecto al archivo original y puede repetirse sin duplicar registros.

Selecciona el JSON v2 de OXI-2026. No selecciones el CSV ni el archivo de Finanzas.
La importación conserva los datos que vienen del registro de reservaciones. Si después se ajusta el precio, se aplica un descuento o se corrige un abono, actualiza primero el registro de origen y vuelve a importar. Las cortesías institucionales se mantienen separadas de los ingresos ordinarios; las notas se conservan como observaciones.

Las cotizaciones no son compromisos; los anticipos se registran como pagos y no se suman otra vez como egreso. Los egresos registrados muestran obligaciones confirmadas y egresos adicionales; los egresos pagados muestran flujo de efectivo. Los importes importados de reservaciones conservan su referencia externa para evitar duplicados. El archivo publicado en GitHub se usa como plantilla inicial, no como base de datos compartida.

Ruta de evolución del sistema

Preparar el módulo financiero para crecer sin perder trazabilidad ni duplicar registros.

Base común de movimientos

Cada ingreso, egreso, compromiso o pago tendrá identificador estable, fecha, periodo, categoría, origen, referencia relacionada y estado. Se distinguirán importes previstos, comprometidos y efectivamente cobrados o pagados.

Próximos módulos por etapas

1. Mejoras de reportes y conciliación. 2. Cuotas y padrón de socios. 3. Costos fijos y variables de instalaciones. 4. Consolidado por evento, periodo y Consejo Directivo.

Por ahora, este panel es una guía de trabajo; no crea módulos nuevos ni cambia el cálculo de los movimientos existentes.
