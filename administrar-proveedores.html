Cómo guardar los cambios en el proyecto

  1. Importa y valida el JSON que quieras revisar.
  2. Exporta el catálogo validado desde esta página.
  3. En GitHub, abre data/proveedores.json.
  4. Reemplaza su contenido por el JSON exportado y guarda el cambio.
  5. Vuelve a cargar el catálogo publicado para comprobar el resultado.

No subas información confidencial de proveedores a un repositorio público. Antes de reemplazar el archivo publicado, conserva una copia del JSON anterior.
